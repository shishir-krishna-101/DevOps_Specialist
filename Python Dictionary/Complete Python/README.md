## Sources

Primary references for these topics are the official Python documentation and, where applicable, the official Python Packaging User Guide.

- Python documentation: https://docs.python.org/3/
- Python Tutorial: https://docs.python.org/3/tutorial/
- Python Standard Library: https://docs.python.org/3/library/
- Python Packaging User Guide: https://packaging.python.org/en/latest/

The sources provide the technical foundation; the topic files will organize that information into learner-friendly explanations and practical exercises.
